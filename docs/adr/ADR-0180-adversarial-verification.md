v18 prioritizes falsification over feature count. Safety claims must survive generated property corpora,
state-machine exploration, mutation gates, malformed-input boundaries, concurrency models, restore admission,
numeric edge cases and supply-chain scrutiny. Model/static PASS is not a substitute for dependency-backed,
live PostgreSQL, HTTP runtime or human C5 evidence.
