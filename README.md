# Medical OS v0.5 Repository Bootstrap

This repository is a bootstrap generated from the frozen Medical OS authorities and Traceability Registry v0.4.

It is **not** a production-ready clinical system. It establishes typed contracts, fail-closed validation, safety registries, state-machine primitives, AI Safety Envelope primitives, and CI admission gates.

The remaining authority adjudications must be explicitly reviewed; code cannot convert semantic similarity into authority.
